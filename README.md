# 红果短剧下载器 v0.0.1

一个本地的红果短剧**批量解析 / 下载 / 管理**工具（Electron 桌面应用，Windows 优先）。

## 功能特性

- **解析**：支持短剧分享链接、页面 URL、纯 `series_id` 或直接粘贴分享文案，自动识别并拉取全剧集列表
- **集数选择**：全选 / 反选 / 取消、前 10 / 前 30 / 后 30 快捷选、自由范围（如 `1-30` 或 `1,5,10`）
- **批量下载**：
  - 并发数可调（1–10）
  - **Range 断点续传**：中断后继续，不从头再来
  - **失败自动轮询重试**：退避重试（5s/10s/20s/40s/60s，最多 5 次），仍失败才进「下载失败」列表
- **下载管理**：
  - 「下载中 / 已完成 / 下载失败」三分类，**每个分类均按短剧分组并可折叠**
  - 分组头**吸顶固定**，长列表滑到哪都能看到当前短剧名与进度
  - 列表**独立滚动条**，页头（标题/工具栏/标签）始终固定
  - 单条操作：暂停 / 继续 / 取消 / 打开文件夹 / 从列表移除
  - 批量操作：全选、暂停选中下载、取消选中下载、重试选中、删除选中、全部暂停、全部继续、停止全部、清空已完成、清空失败
- **历史记录**：解析输入框带历史下拉，点击记录可一键回填并重新解析
- **下载记录**：按短剧聚合的永久记录（下载时间 / 已下载集数 / 存放目录），可直达文件夹或重新解析
- **关于**：侧边栏底部「关于」，含应用版本号
- **全部结束通知**：下载队列清空后弹系统通知 + 页内提示条

## 技术架构

| 层 | 技术 |
|---|---|
| 主进程 | Electron（窗口、下载泵、断点续传、解密、IPC） |
| 渲染层 | 原生 HTML / CSS / JS（零运行时框架，自研增量渲染引擎，千级任务不卡） |
| 持久化 | 单一本地 JSON（`store.js`，异步写盘 + 紧凑格式） |
| 逆向复用 | 基于逆向分析还原的签名引擎（`src/native/sixgod/`）、取流与 CENC-AES-CTR 解密逻辑（合规边界内复用协议参数） |

## 运行方式

> 本项目基于 Electron，运行时依赖已随项目附带的 `node_modules/electron`。

1. 双击 **`启动.cmd`** 即可启动；或在项目目录执行：

```bash
npm start
```

2. 首次解析需要联网（签名/取流依赖官方接口）。
